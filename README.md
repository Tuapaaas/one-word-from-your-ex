One word my ex would use to describe me: **Unavailable**. Present in the room, absent in every way that counted — the funniest, most painfully honest word I could own.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

This writes exactly `Unavailable` (11 characters, one word) to `/output/entry.txt`.
